I'm not an engineer, and I don't write code by hand. AI writes it. I bring the words and make the calls. This week: how to get a simple one-page website live that way, with a link you can share, in about an hour.

The mistake that wastes the most time is asking AI for a design before you know what the site should say. You get a lovely layout full of placeholder text, then spend the evening asking for changes because nothing fits your real words. Do it in the other order.

1. Words before design

Decide the one job of your site first. Get hired, sell a service, collect emails or show your work: pick one. Write it as a single sentence, for example "Help café owners in my area book me for menu photos."

Then write the content before you think about colours: a headline, a two-line intro, three short sections, some proof (projects, numbers, a quote you have permission to use) and one clear next step such as "Email me". Let AI interview you for it. Ask it to "interview me one question at a time to write the content for a one-page website whose job is [your sentence]". Answering questions is far easier than facing a blank page.

2. The single-file trick

When you ask AI to build the site, ask for one single HTML file with everything inside it. HTML is the language web pages are written in. A single file means the layout, colours and text all travel together: nothing to install and no separate pieces to lose. That one file is a complete website.

Review it on your phone first, since that's where most visitors will see it. Then ask for changes in rounds: structure first, then words, then small details. One round at a time works far better than ten changes in one message.

When you're happy, download the file, or copy the code into a new plain-text file. Name it index.html. Web hosts treat a file with that name as your home page. Put it alone in a folder named after your site.

3. Going live with Netlify Drop

Netlify is a hosting service: it puts your files on the internet. Its Drop page lets you do that by dragging a folder into your browser.

  1. Sign in to Netlify, or create a free account. You can drop without an account, but the site then sits behind a temporary password until you claim it by signing up.
  2. Open Netlify Drop in an up-to-date Chromium-based browser such as Chrome or Edge. A laptop is easiest.
  3. Drag your folder onto the drop area. A zip of the folder works too.
  4. After a few seconds you get a live link ending in netlify.app. Open it on your phone.
  5. For a nicer link, open your project overview, choose Customize, then "Manage project name and cover image". The project name becomes your address, like yourname.netlify.app.

To update the site later, ask AI for the change, save the new index.html in the same folder and drag the folder onto the Production deploys area of your project dashboard.

Checked in October 2026 against Netlify's Drop quickstart. If a button has moved, search Netlify's docs for "Netlify Drop".

Heads-up

Everything on your site is public. Leave off your home address, private phone number and ID details. Before you add a contact form or collect emails, read the launch checklist.

Prompt of the week

Use this once your words are written. It asks for one file, sets the style in a few words and makes the AI check what's missing before it builds.

Build my one-page website as a single HTML file, with all the styling inside the file.

Job of the site: [your one sentence]
Content: [paste your headline, intro, sections, proof and contact details]
Style: [3 words, e.g. calm, bold, warm], with [one colour] as the accent.

Must: work well on phones, load fast, have a light and a dark mode, and use only my real text (no placeholder text).
Avoid: a stock-photo look, lots of animation, everything centred.

Before you build, ask me up to 3 questions if anything important is missing. After you build, tell me the 3 things you'd improve first.

Try this today

Don't build yet. Spend 20 minutes on step 1 only: write the one-sentence job, then let AI interview you and draft the words. Read them out loud. If you'd be happy for a stranger to read them, you're ready, and the build itself will go much faster when you sit down to do it.
