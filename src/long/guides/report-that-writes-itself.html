If every Monday starts with copying numbers out of a spreadsheet and turning them into sentences for someone else, this page is for you. You'll set up a tracker where the spreadsheet does all the maths, a report template, and one prompt that turns the numbers into a short, honest summary. Then you'll pick a no-code way to run it every week: a scheduled task in Claude or ChatGPT, Gemini inside Google Sheets, or Zapier. Setup takes about 90 minutes spread over a week. After that, checking and sending the report takes about 10 minutes.

In short
  • The one rule: the spreadsheet calculates, the AI only writes about numbers it's given. It never does the maths.
  • Build a summary tab with formulas for this week, last week, change and target, so the AI reads one small table.
  • Run the prompt by hand for three weeks before automating it. If it isn't good by hand, automation just makes it wrong faster.
  • Automate with a Claude scheduled task (paid plans), Gemini in Sheets, a ChatGPT task or Zapier, and have it produce a draft, never a send.
  • Spend two minutes each week checking every number in the draft against the sheet.

The one rule: the sheet does the maths

Language models are good at writing about numbers and unreliable at calculating them. Ask one to work out a percentage change across 40 rows and it may get it right, or may produce something plausible and wrong, with no warning either way. In a weekly report that someone acts on, "plausible and wrong" is the worst outcome.

So split the job. Formulas calculate every number the report mentions: totals, changes, averages, targets. The AI receives a small, finished table and does only what it's good at: noticing what matters, putting it in order and writing clear sentences. The prompt then forbids it from calculating anything new.

My take

In years of running creator campaigns, the reports that caused trouble were rarely the ones with bad results. They were the ones where a number didn't match the source. This rule exists to stop that.

Step 1: Set up the tracker

Make a tab called Data. Use one row per week and one column per number, with the week's start date in column A. No merged cells, no blank rows, no totals mixed in. A clean, boring table is what every tool on this page reads best.

Here's the worked example used through this page: a small online shop selling candles. The numbers are invented for illustration.

The real sheet also has columns E and F for newsletter sign-ups (97, then 85 in the last two weeks) and returns (4, then 9). Pick five to eight numbers at most. A report with twenty metrics gets skimmed.

Tip

If your numbers come from another tool (a shop, an ad account, a CRM), check whether it can export to Google Sheets or whether Zapier can add a row each week. Typing five numbers on a Friday is also fine. Consistency matters more than automation here.

Step 2: Add a summary tab with formulas

Make a second tab called Summary. This is the only thing the AI will read. One row per metric, with these columns:

ColumnWhat it holdsFormula for Orders (row 2)
A: MetricThe nameOrders
B: This weekLatest row in Data=INDEX(Data!B:B, COUNTA(Data!A:A))
C: Last weekThe row before=INDEX(Data!B:B, COUNTA(Data!A:A)-1)
D: ChangePercentage change=IF(C2=0, "", (B2-C2)/C2)
E: TargetTyped in by you130
F: StatusOn or below target=IF(B2>=E2, "on target", "below target")

Copy the row down for each metric, changing Data!B:B to the right column (C for revenue, D for ad spend and so on). Format column D as a percentage. The formulas assume a header in row 1 of Data and no blank rows.

Add rows for derived numbers too, calculated in the sheet. For the shop: revenue per € of ad spend (=B3/B4 if revenue and ad spend are rows 3 and 4) and average order value (revenue divided by orders). If the AI needs a number, the sheet should already contain it.

Step 3: Write the report template

Decide the shape before you write the prompt. A fixed shape makes the report quick to read and makes errors obvious, because the reader knows where to look. This template works for most weekly reports:

  1. Headline: one sentence on the week.
  2. Numbers: the summary table, unchanged.
  3. Wins: up to three, each tied to a number.
  4. Watch: up to two concerns, each tied to a number.
  5. Next week: one or two actions, each with a reason.
  6. Open questions: anything the data can't explain.

"Open questions" is the section most AI reports miss. It's where the AI says "returns doubled, and the data doesn't say why", instead of inventing a reason.

Step 4: Write and test the prompt

You are writing a weekly report for [reader, e.g. my business partner] about [what, e.g. our online candle shop].

Here is this week's summary table. Every number is already calculated:
[paste the Summary tab, or name the file and tab if you have a connector]

Rules:
- Use only numbers that appear in the table, exactly as written. Do not calculate, round, estimate or add any new number.
- If you think a number is wrong or missing, say so under "Open questions" instead of fixing it.
- Do not guess causes. If the data doesn't explain a change, say that.
- Plain British English, short sentences, no hype words. Amounts in €.

Format:
Headline: one sentence.
Numbers: the table as given.
Wins: up to 3 bullets, each quoting the number it's based on.
Watch: up to 2 bullets, each quoting the number.
Next week: 1 or 2 actions, each with a one-line reason.
Open questions: anything the data can't answer.

Keep it under [200] words, excluding the table.

Run it by hand for three weeks: paste the summary into a chat, read the result, and fix the prompt when something's off. A Claude or ChatGPT Project is a good home for this, with the prompt in the instructions and last week's report as a file (see Projects in Claude and ChatGPT, explained).

What good and bad output look like

Weak

"Fantastic week! Revenue grew by around 25%, driven by the new autumn scent range, and conversion rates improved significantly. Returns rose slightly, which is normal for this time of year."

Better

"Headline: Orders beat target (142 against 130) while ad spend fell 4.7%. Watch: returns rose from 4 to 9 (+125.0%), and sign-ups fell 12.4% to 85. Open questions: the data doesn't show why returns rose. Worth checking the reasons logged in the shop."

The weak version invents a figure (revenue rose 16.4%, not "around 25%"), invents a cause (the autumn range isn't in the data), mentions a metric that isn't tracked (conversion rate) and plays down a real problem. Every one of those is a reason to tighten the prompt.

Heads-up

Don't paste customer names, emails, addresses or payment details into the report data. Aggregate numbers are all the AI needs. If the sheet holds personal data, build the summary tab from it and share only that.

Step 5: Automate it (pick one route)

Once the prompt has produced a good report three weeks running, move it to a schedule. Every route below ends in a draft for you to check, not a sent message.

Route A: a Claude scheduled task

Scheduled tasks run a prompt on a timetable, in the cloud, even when your computer is off. According to Anthropic's scheduled tasks page, they're on paid plans (Pro, Max, Team and Enterprise) and can use your connectors. Web and mobile were still in beta when I checked.

  1. Connect Google Drive and Gmail (see the connectors worth setting up first).
  2. Click Scheduled in the sidebar, then New task, then Set up manually (or Create with Claude to be guided).
  3. Name it "Weekly report", paste the prompt below, choose weekly, pick Monday at a time before you start work, and save.
  4. Use the option to run it now, and read the result.
Every Monday:
1. Open the Google Sheet "[sheet name]" in my Drive and read only the "Summary" tab.
2. Write the weekly report using the rules and format below.
3. Save it as a Gmail draft to [reader's email] with the subject "Weekly report, week of [date from the Summary tab]". Do not send it.
4. If the Summary tab looks empty, unchanged from last week or has errors (#REF!, #DIV/0!), don't write the report. Create a draft to me instead, saying what's wrong.

[paste the rules and format section from Prompt 2]

Route B: a ChatGPT scheduled task

ChatGPT's tasks work on every plan, with limits: Free and Go allow 3 active tasks, at most once a day, and Plus allows 5, per OpenAI's tasks page. Open Scheduled and describe the task in plain words. Two cautions from that page: tasks can use supported apps (it names Gmail, Slack and GitHub as examples), so check your data source works in a task before relying on it; and a task created inside a Project can't read that Project's files. If your sheet can't be reached, use the task as a Monday reminder that includes the prompt, then paste the summary yourself.

Route C: Gemini in Google Sheets

If you have an eligible Google Workspace or Google AI plan, click Ask Gemini at the top right of the sheet to open the side panel (Google's help page). It reads the sheet directly, so there's no pasting. It isn't scheduled, and Google notes that side-panel chats aren't saved, so keep the prompt in a cell or a doc. Charts it creates don't update when the data changes.

Read only the "Summary" tab of this spreadsheet. Don't calculate any new numbers or change any cells. Write a weekly report with: a one-sentence headline, up to 3 wins and 2 concerns (each quoting the number from the tab), 1 or 2 actions for next week, and open questions the data can't answer. Under 200 words, British English, amounts in €.

Gemini can also run scheduled actions (up to 10 active, with Keep Activity on), and actions that use Google apps need them connected, according to Google's page. Test whether yours can read the sheet before relying on it. More in Gemini for people who live in Google.

Route D: Zapier

Zapier is the most reliable timetable because it doesn't depend on a chat app. The Zap has four steps:

  1. Trigger: Schedule by Zapier, Every Week. Pick Monday and a time. Schedule triggers don't count towards your task usage (Zapier's page).
  2. Google Sheets: an action that looks up the rows of your Summary tab.
  3. AI by Zapier: paste Prompt 2's rules and format, and map the Sheets fields into the table section.
  4. Gmail (or Outlook): an action that creates a draft, not one that sends.

Check the costs first. In October 2026 Zapier's free plan allowed only two-step Zaps and 100 tasks a month, and AI by Zapier wasn't on the free plan, so this needs a paid plan (from about $20 a month on Zapier's pricing page). Make is an alternative: its free plan included 1,000 credits a month and 2 active scenarios, but its built-in AI tools were on paid plans (Make's pricing). Step 6: Check it every week

Automation removes the typing, not the responsibility. Before you send, spend five minutes on this checklist:

  1. Every number matches the sheet. Tick them off one by one. This is the check that matters most.
  2. No new numbers. If the draft contains a figure that isn't in the summary tab, it was invented or calculated.
  3. No invented causes. "Because of the new range" needs evidence. If it isn't in the data, cut it or move it to open questions.
  4. The bad news is there. Compare the "Watch" section with the summary tab's "below target" rows.
  5. It's the right week. Check the date. Stale data is the most common silent failure.

You can get a second pass from the AI too, in a fresh chat:

Here is a summary table and a report written from it.
Table: [paste]
Report: [paste]

Check the report against the table. List, as a table: every number in the report, whether it appears in the table exactly (yes or no), and the matching cell. Then list any claim about causes that the table doesn't support. Don't rewrite the report.

Treat this as an extra check, not a replacement for yours. An AI can miss a mismatch too.

Where this goes wrong

  • The AI still does maths. Even with the rule, a model may write "almost double" or round 16.4% to "about 15%". The weekly check catches it.
  • Broken formulas pass silently. A new column or a blank row can shift every number. Add a "last updated" cell to the summary tab and have the prompt report it.
  • It sounds confident about nothing. Small numbers swing wildly: 4 returns to 9 is +125%. Tell your reader when a change is based on small counts.
  • It can't explain why. The sheet holds what happened, not why. Causes come from you, your team or your customers.
  • Schedules fail quietly. Connectors expire and tasks pause. If no draft arrives on Monday, look before the reader asks.

When it gets stuck

  • The report quotes the wrong numbers. It may be reading the Data tab. Name the Summary tab in the prompt and say "read only this tab".
  • It keeps adding commentary you don't want. Add a rule, such as "No general advice. Only comment on numbers in the table."
  • The scheduled task can't find the sheet. Check the Drive connector is connected and the file name in the prompt matches exactly, including capitals.
  • Formulas show #REF! or #DIV/0!. A column moved or last week was zero. Fix the sheet; the prompt in Route A tells the task to stop and warn you.
  • The report is too long. Lower the word limit and cap the bullets. Readers prefer five lines they read to twenty they skip.

Questions people ask

Can't I just upload the raw data and ask for a report?

You can, and for a one-off it may be fine. For a report someone relies on every week, it's risky: the AI may calculate something wrongly with no warning. Letting formulas do the maths makes errors much rarer and much easier to spot.

Does this work with Excel?

The method does. The formulas on this page work in Excel too. The automated routes are easiest with Google Sheets, because the Drive connectors and Zapier read it directly.

Which automation route should I pick?

If you already pay for Claude and use Google, Route A. If you live in Google Workspace with Gemini, Route C, run by hand each Monday. If the report must arrive whatever happens, Route D. If you're not sure, stay manual for a month; it's only five minutes.

Can I use this for client reports?

Yes, with care. Check your contract and the client's rules on sharing their data with AI tools, send aggregated numbers only, and always review before sending. For influencer campaigns, the structure in The influencer campaign report clients actually read pairs well with this setup.
