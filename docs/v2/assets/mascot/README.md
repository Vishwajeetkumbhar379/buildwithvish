# Vish mascot pack

31 transparent PNGs, recovered losslessly (image plus alpha mask) from `Vish_Mascot_Reference.pdf` on 28 Oct 2026. Raster renders, not a 3D model or rig. `_contact-sheet.png` shows all of them.

- `01-sides/`: 8 views for a turnaround (512×768).
- `02-expressions/`: 9 chest-up expressions (512×512).
- `03-gestures/`: 8 presenter poses; left and right refer to the screen (512×768).
- `04-wave/`: 6 greeting keyframes, in order (512×768).

Identity rules are in `../../CONTEXT.md`, section 6.
